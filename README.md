## Development rules

- Work in this Preview repository only.
- Preserve existing local career saves.
- Do not add simulated purchases or fake ad rewards.
- Real ads, in-app purchases, premium currency, and bundles remain planned for a later monetization phase after economy validation.
- A successful Pages deployment or JavaScript syntax check does not replace interactive browser testing.
- Do not publish changes to the production repository without explicit approval.
